# Клавиши командной строки

Для нашего общего окружения Zsh. Проверено в задаче 036.
В программах, запущенных внутри терминала, могут быть свои назначения.

| Клавиша | Действие в строке Zsh |
|---|---|
| Tab | Дополнение команд, имён файлов и путей |
| ↑ | Поиск в истории через Atuin |
| ↓ | Следующая запись истории |
| Ctrl+R | Поиск в истории через Atuin: ввести часть команды |
| Ctrl+A / Ctrl+E | Перейти в начало / конец строки |
| Ctrl+U / Ctrl+K | Удалить от курсора до начала / конца строки |
| Ctrl+W | Удалить предыдущее слово |
| Ctrl+L | Очистить экран с сохранением набранной строки |
| Ctrl+C | Прервать текущую команду или отменить набранную строку |
| Ctrl+D | На пустой строке — выйти; иначе удалить символ справа или показать дополнения |
| Delete | Удалить символ справа от курсора; в конце строки ничего не делать |
| Backspace | Удалить символ слева от курсора |
| Ctrl+← / Ctrl+→ | Перейти на слово назад / вперёд |

Delete передаётся терминалом как управляющая последовательность,
обычно Esc [ 3 ~. Если она не назначена в Zsh, может появляться `~`.
В общем модуле назначены как эта последовательность, так и вариант,
указанный в описании терминала (terminfo).

После применения новой конфигурации открыть новую оболочку.
Для исправления Delete в уже открытой оболочке:

```sh
bindkey '^[[3~' delete-char
```

Настройка Ctrl+U для уже открытой оболочки:

```sh
bindkey '^U' backward-kill-line
```

Настройки: `nixos-config/home-manager/modules/zsh.nix` и `atuin.nix`.
[Справка Zsh](https://zsh.sourceforge.io/Doc/Release/Zsh-Line-Editor.html).
