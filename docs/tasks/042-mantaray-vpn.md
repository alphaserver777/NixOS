# MantaRay для компьютеров с рабочим столом

Дата: 2026-10-27. Состояние: выполняется.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT; связан опыт упаковки задачи 003 и сохранение настроек 040.
Пользователь прислал инструкцию и выбрал установку на всех компьютерах
с рабочим столом. Другие физические машины автоматически не обновлять.

## Цель и область

Добавить воспроизводимый пакет MantaRay и системную службу управления
туннелем в общую конфигурацию графических машин. Определять наличие
рабочего стола по включённым Hyprland или Xserver, не по имени машины.
Проверить пакет, вычисление конфигураций всех шести машин и сборку main.
Не менять действующее подключение, маршруты, DNS, Clash и Amnezia;
не импортировать личную подписку и не подключать VPN автоматически.

## Факты и решение

Инструкция:
https://de2c580e-a390-4567-88f8-e7d8099376cf.selstorage.ru/instructions/s/instructions/linux/index.html

В инструкции указана 2.33.5; метаданные опубликованного Debian-пакета
сейчас содержат 2.35.3, amd64. Установщик требует библиотеки Flutter/GTK,
сетевые команды, группу mantaray-vpn и службу
com.mantaray.vpn.service. Скрипты установки Debian не выполнять.
Упаковать файлы через Nix, закрепить содержимое контрольной суммой;
пути и системную службу адаптировать декларативно.

## Критерии и проверка

- [ ] Пакет собран; исполняемые файлы находят зависимости и ресурсы.
- [ ] Служба, доступ к сокету, пути и группа соответствуют пакету.
- [x] Вычислены все шесть конфигураций: установка только с рабочим столом.
- [ ] Сохранены зависимости flake, драйвер, шрифты, курсор и режимы экранов.
- [ ] main собран из записанного коммита; применение проверено отдельно.
- [ ] Личная подписка не записана в Git, соединение VPN не включалось.

Проверки: содержимое архива и исходные служебные скрипты, сборка пакета,
проверка ELF-зависимостей, проверка запуска без подключения VPN,
вычисление условий модуля для всех машин, проверочная и полная сборки main.
Долгие загрузки и сборки оставить отдельной службе; проверка через 3–5 минут.

## Возврат

Материалы: ~/.local/state/mantaray-20261027T164108Z. До применения
сохранить /run/current-system; отменить импорт модуля и собрать систему
либо вернуть предыдущее поколение. Не удалять личные конфигурации.
При первом запуске может потребоваться новый вход для обновления групп,
как указывает инструкция производителя; сеанс автоматически не завершать.

## Ход работы

Обработка архива не запускала установочные сценарии Debian.
Графическое приложение использует Flutter/GTK; служба — статический ELF,
Python нужен только штатному установщику обновлений Debian, который
исключён из пакета вместе с его политикой привилегий. Обновлять приложение

не поддерживается. Личные подписки и обновление списков серверов этим
ограничением не затрагиваются.

определяется параметрами рабочего стола, а не фиксированным списком.
