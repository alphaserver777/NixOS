# Задача 044: исправление Happ

## Проверка контекста

Прочитаны WORKFLOW.md, constitution.md, architecture.md, devplan.md,
DEPLOYMENT.md, tasks/PROCESS.md и задача 003.

## Статус

В работе.

## Причина и цель

Пользователь сообщает о неработающем Happ. Установлен выпуск 2.17.1,
в задаче 003 отмечены ошибки окон настроек; системная служба туннеля
не установлена. Подготовить актуальный выпуск и декларативную службу
с проверкой запуска в NixOS.

## Область изменения

Пакет packages/happ.nix и общий модуль nixos/modules/happ.nix.
Проверить все конфигурации, использующие модуль; применить только main.
Сохранить подписки, настройки пользователя и возможность ручного выбора
между Clash, MantaRay и Happ. Автоматически соединения не переключать.
Не обновлять flake.lock, ядро, драйверы и другие приложения.

## План

1. Проверить официальный пакет 4.6.0, состав службы и контрольную сумму.
2. Исправить упаковку и добавить необходимую службу без установщика Debian.
3. Проверить зависимости, запуск интерфейса и службы, вычисление хостов.
4. Зафиксировать изменения, собрать main и проверить план применения.
5. Применить main, проверить службу и дать пользователю порядок проверки
   соединения при отключённых конкурирующих туннелях.

## Условия завершения

- [ ] Пакет собирается, библиотеки доступны, интерфейс открывается.
- [ ] Служба доступна из приложения в NixOS.
- [ ] Проверены затронутые конфигурации; main собран и применён.
- [ ] Соединение и открытие сайтов подтверждены пользователем.

## Проверка

Сборка закреплённого изменения, отдельный графический сеанс с временным
домашним каталогом для безопасной проверки, проверка службы и её журнала.
Перед применением — dry-activate, сравнение ядра и списка изменяемых служб.
Личные подписки и ключи в вывод и репозиторий не помещать.

## Возврат

Сохранить путь предыдущей системы. Применить его через
`sudo nixos-rebuild switch --no-reexec --store-path ПУТЬ`.
Сохранённые данные Happ не изменять при проверках; если новая версия
потребует изменения формата, предварительно создать закрытую резервную копию.
