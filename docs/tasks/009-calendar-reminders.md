# Календарь, задачи и звуковые напоминания

Состояние: выполняется.

Правила работы, архитектура, план, применение и задачи 007–008 прочитаны.
Пользователь одобрил установку DankCalendar и Dank Calendar Plus.

Цель: готовый виджет в верхней панели DMS, локальный список задач и
повторяющиеся события с уведомлениями и звуком. «Разминка» ежедневно
в 08:15 и 17:15, часовой пояс Europe/Moscow.

Отдельный модуль Home Manager устанавливает закреплённый официальный
выпуск календаря и закреплённое расширение. Служба запускается при входе.
Первоначальная настройка добавляет виджет, не сбрасывая настройки панели.
Напоминания отправляет календарь; дублирующие уведомления расширения
отключаются. Записи создаются однократно в личном локальном календаре,
последующие применения системы не восстанавливают удалённые пользователем
события. Существующие календари и списки сохраняются.

Область: общий модуль оформления desktop-хостов; применение только x-disk.
Системные службы, VPN, оформление и версии существующих пакетов не меняются.
По прямому указанию пользователя проверка новой программы выполняется
локально до применения системы; другие физические компьютеры недоступны.

Проверка:

- [ ] Календарь запускается, окно открывается и закрывается без ошибок.
- [ ] Виджет открывает события и список задач из верхней панели.
- [ ] Два ежедневных события имеют правильное время и напоминание в момент начала.
- [ ] Пробное напоминание даёт уведомление и запускает воспроизведение звука.
- [ ] Сборка системы успешна; служба активна, ошибки DMS и Hyprland отсутствуют.

Возврат: поколение 269 системы и предыдущий commit main. Личные данные
календаря хранятся вне /nix/store и сохраняются при возврате. Перед первым
запуском создаётся копия настроек DMS и существующих настроек календаря.
