# Общая служба ключей SSH для VS Code и терминала

Состояние: выполняется. Дата: 14 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, задача 029 и руководство ssh_agent_guide_ru.

## Причина и цель

Ключ добавлен в единственную ssh-agent.service, перезапусков службы нет.
SSH из терминала успешно авторизуется в GitHub без запроса пароля.
Процессы VS Code запущены без SSH_AUTH_SOCK. Пользователь подтвердил,
что повторный запрос пароля возникал именно в VS Code.
Обеспечить доступ к уже разблокированному ключу из редактора.

## Решение и область

В модуле Home Manager sshAgent.nix добавить отдельное правило клиента SSH:
если адрес службы не получен из окружения и локальная служба доступна,
использовать /run/user/%i/ssh-agent. Существующий адрес в окружении,
в том числе адрес переданной по SSH службы, сохранить. Явные настройки
пользователя имеют приоритет. Не отключать защиту ключа паролем.

Конфигурация ~/.ssh/config остаётся изменяемой для LazySSH. Через отдельный
шаг применения Home Manager добавить в конец файла включение управляемого
фрагмента, предварительно сохранив копию. Повторное применение не добавляет
дубликаты. Настройки серверов, ключи, открытые окна не изменять.
Настройка общая для пользователей с включённым модулем; применить только
на текущем x-disk. Другие компьютеры — вычисление конфигурации.

Применять только собранный шаг sshAgentClientConfig из Home Manager,
без применения накопившихся за четыре дня других изменений системы.
Собранный шаг сохранить отдельной ссылкой Nix до очередного полного
применения Home Manager. Для нового подключения из Code перезапуск
редактора не требуется: файл конфигурации SSH читается при подключении.

## Проверка

- [ ] При отсутствии SSH_AUTH_SOCK SSH использует действующую службу.
- [ ] Настройки серверов, существующий адрес службы и явный IdentityAgent
  сохраняются; повторное применение не добавляет дубликаты.
- [ ] Git читает список веток репозитория без переменной SSH_AUTH_SOCK и
  с запрещённым запросом пароля, как процесс из текущего VS Code.
- [ ] Настройка вычисляется в Home Manager на Huawei, main и x-disk.
- [ ] Изменения зафиксированы, результат и ограничение после перезагрузки
  записаны.

## Возврат

Сохранить ~/.ssh/config в закрытом каталоге
~/.local/state/ssh-agent-client. Для возврата убрать только добавленный
блок включения и управляемый фрагмент; копия исходного файла доступна.
Не восстанавливать копию поверх более поздних записей серверов.
SSH-agent не перезапускать и ключи не удалять. После перезагрузки пароль
ключа по-прежнему вводится один раз; автоматическое постоянное хранение
пароля не входит в задачу.

Документация: https://man.openbsd.org/ssh_config#IdentityAgent.
