# Задача 045: обратные маршруты при работе Happ

## Проверка контекста

Прочитаны WORKFLOW.md, constitution.md, architecture.md, devplan.md,
DEPLOYMENT.md, tasks/PROCESS.md, задачи 003 и 044.

## Статус

В работе.

## Причина

После задачи 044 Happ подключается, но пользователь сообщает о потере
интернета. Во время попытки 2026-10-27 20:59:28–20:59:57 собраны вывод
Xray и изменения сетевой конфигурации. Clash отключён в 20:59:32;
проблема сохраняется до отключения Happ.

Happ создаёт интерфейс happ-xray, устанавливает основной маршрут через
него с метрикой 1; прежний маршрут enp5s0 имеет метрику 100. Xray
выбирает enp5s0 для исходящих соединений. На main действует строгая
проверка обратного маршрута NixOS: правило `fib saddr . mark . iif oif`
отбрасывает ответы, если обратный маршрут выбран через иной интерфейс.
Это несовместимо с такой схемой туннеля. Прямые TCP-подключения через
enp5s0 к выбранному серверу и контрольным адресам проходят.

## Цель и область изменения

В общем модуле Happ задать рекомендованный NixOS для асимметричной
маршрутизации режим `networking.firewall.checkReversePath = "loose"`.
Сохранить межсетевой экран и остальные его правила. Значение по умолчанию
может быть переопределено хостом. Затронуты Huawei, main, x-disk, srv-home.
Два хоста без этого модуля сохраняют прежнюю настройку.
Применить только main; чужие соединения автоматически не переключать.
Ядро, драйверы, подписки и закреплённые зависимости не менять.

## План и условия завершения

- [ ] Вычислить все конфигурации и проверить область действия.
- [ ] Собрать main из зафиксированного изменения; проверить план применения.
- [ ] Применить main, проверить изменённое правило и сохранение остальных правил.
- [ ] Пользователь подтвердил открытие сайтов через Happ.

## Проверка

Сохранить предыдущую систему и правила межсетевого экрана. До применения
сравнить ядро, параметры модулей и изменяемые службы. После применения
проверить наличие проверки достижимости источника без требования того же
интерфейса, включённый firewall и исправность happd. Сравнить правила
фильтрации и маршруты, чтобы исключить посторонние изменения.
Повтор подключения пользователь выполняет вручную, без одновременных
туннелей Clash и MantaRay. Успешная сборка не доказывает передачу трафика.

## Возврат

Применить предыдущую систему через
`sudo nixos-rebuild switch --no-reexec --store-path ПУТЬ`.
Предыдущая система сохранена в каталоге проверки задачи 045.
