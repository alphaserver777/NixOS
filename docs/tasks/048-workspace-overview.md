# Задача 048: единый обзор рабочих столов

## Контекст и статус

Выполнено. Прочитаны WORKFLOW.md, constitution.md, architecture.md,
devplan.md, DEPLOYMENT.md, tasks/PROCESS.md и задача 041.
Пользователь хочет по Win+Tab тот же обзор, что по правой кнопке на
переключателе рабочих столов DankMaterialShell.

## Изменение и границы

В общем home-manager/modules/hyprland/binds.nix заменить команду
Hyprspace на `cosmic-dms ipc hypr toggleOverview`. Команда вызывает
тот же объект hyprlandOverviewLoader, что и правая кнопка панели.
Затронуты Huawei, main и x-disk. Пакеты, зависимости, размещение окон,
другие сочетания клавиш и настройки мониторов сохраняются.

## Проверка и применение

- [x] Вычислить сочетание для всех трёх рабочих машин.
- [x] Собрать файл hyprland.conf средствами Home Manager для x-disk.
- [x] Убедиться, что с текущим файлом отличается только Win+Tab.
- [x] Применить только полученный файл и перечитать настройки Hyprland.
- [x] Проверить отсутствие ошибок, открытие и закрытие обзора DMS.

Применение из зафиксированного изменения. Для этой небольшой правки
используется только файл, созданный Home Manager: заменить ссылку
~/.config/hypr/hyprland.conf на собранный результат, сохранив предыдущую
ссылку и постоянную ссылку на результат в ~/.local/state.
Полное переключение системы и окружения не требуется. Это ограниченное
применение результата Home Manager без ручного изменения текста настроек;
следующее полное применение использует ту же правку из репозитория.
Другие машины проверяются вычислением без удалённого применения.

## Возврат

Восстановить прежнюю ссылку из закрытого каталога проверки и выполнить
`hyprctl reload`. В исходниках вернуть прежнюю команду Win+Tab.
Предыдущее поколение системы сохраняется; перезагрузка не нужна.
