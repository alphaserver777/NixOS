# Возврат проверенного режима HDMI на main

Состояние: завершена. Дата: 2026-10-25.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT; связаны задачи 034–036. Работа в fix/main-display-clarity.

## Причина и область

После применения исправления Zsh пользователь увидел кратковременное
синее окно с сообщением monitor hdmi 1 failed. Полный текст не сохранён.
Сейчас все три монитора включены, ошибок синтаксиса Hyprland нет.
Однако установленная конфигурация по-прежнему требует на HDMI-A-1
2560×1440/59,95 Гц, хотя фактически работает 1920×1080/144 Гц.
Отказы нового режима уже установлены в задаче 034. Оставлять его
в активной конфигурации было ошибкой: повторная загрузка настроек
снова пытается применить режим, который не прошёл проверку.

Восстановить только параметры мониторов main из сохранённого состояния
до задачи 034: HDMI-A-1 1920×1080/144 Гц в (0,0), Philips
1920×1080/60 Гц в (1920,0), LG 1440×900/59,89 Гц в (0,-900).
Общие шрифты и исправление Delete сохраняются. Исследование родного
разрешения отложить до отдельной проверки драйвера и соединения;
не пытаться применять отказавший режим при обычных обновлениях.

## Проверка и применение

- [x] Зафиксировать исправление и задать рабочий режим текущему сеансу.
- [x] Собрать main без обновления зависимостей; проверить план служб,
      неизменность ядра и настроек драйвера.
- [x] Применить и проверить, что именно рабочие режимы записаны в
      установленном файле Hyprland, а фактические параметры совпадают.
- [x] Все три экрана включены; ошибки конфигурации отсутствуют;
      панель активна; rgba=5/hintstyle=3 сохраняются.

Сеанс и приложения не завершать. Материалы и предыдущее поколение:
~/.local/state/main-hdmi-working-mode-20261025. Если сборка долгая,
оставить её отдельной службе и предложить проверить через 3–5 минут.
Возврат поколения: sudo nixos-rebuild switch --rollback; учесть, что
оно снова содержит отказавший режим, поэтому для монитора безопаснее
сохранять возвращённый рабочий режим. Предыдущее поколение до всей
настройки изображения записано также в задаче 034.
