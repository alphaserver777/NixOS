# Поддержка RAR в Double Commander

Состояние: завершена. Дата: 2026-10-25.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, задачи 032 и 033. Основа — b3751d7, ветка
fix/main-display-clarity в Nixos-display-clarity.

## Причина

Пользователь не может открыть/распаковать RAR: Double Commander сообщает
«Не удалось открыть существующий файл» и отсутствие библиотеки.
В настройках для rar включён штатный unrar.wcx. Он загружает
libunrar.so/libunrar.so.5 во время работы. В окружении реального процесса
есть libssh2, но libunrar не находится; загрузчик воспроизводит ошибку.
Установленная утилита unrar и её библиотека в отдельном пути Nix store
автоматически недоступны модулю Double Commander.

У файла пользователя сигнатура RAR5, размер 475313807 байт. Проверка
unrar t с отключённым запросом пароля дала код 11 и только ошибки
отсутствующего/неверного пароля. Это подтверждает шифрование файлов,
но не доказывает целостность архива. Пароль не запрашивался и не
подбирался. Файлы пользователя не распаковывались и не изменялись.

## Изменение и область

Добавить unrar из того же закреплённого nixpkgs-unstable в существующую
обёртку packages/doublecmd.nix: LD_LIBRARY_PATH только для приложения.
Сохранить libssh2 и логику SSH_AUTH_SOCK. Импорт набора пакетов в общем
file-manager.nix должен разрешать UnRAR с его собственной лицензией
unfreeRedistributable, как разрешено глобальной политикой проекта.
Не менять системные пути библиотек, личные настройки модулей,
версии программ, драйверы, шрифты или рабочие режимы мониторов.

Общий пакет получат все использующие его домашние конфигурации.
Применить только на main; другие машины обновятся при следующем
применении этой версии конфигурации. Текущее окно пользователя не
закрывать: после установки библиотека появится в новом процессе.

## Проверка

- [x] До исправления воспроизведено отсутствие библиотеки в окружении
      настоящего Double Commander; после исправления она загружается.
- [x] Готовая обёртка собирается без пересборки самого Double Commander.
- [x] Через штатный модуль или библиотеку прочитать заголовки RAR;
      проверить распаковку небольшого известного файла в отдельную папку.
- [x] В новом процессе приложения сохранены libssh2 и сокет агента.
- [x] Сборка и установка main успешны; проверены план служб, ядро,
      режимы мониторов и отсутствие изменений пользовательского архива.
- [x] Записано ограничение: распаковка личного зашифрованного архива
      требует пароля и без него не считается проверенной.

Запуск проверочных окон — с отдельным каталогом настроек и именем
экземпляра, без показа окна при автоматических проверках. Не использовать
doublecmd --help: эта версия воспринимает его как обычный запуск.
Большие журналы со списками файлов не выводить в разговор.

## Применение и возврат

Исходники зафиксировать до применения. Материалы проверки и путь
предыдущей системы: ~/.local/state/doublecmd-rar-20261025.
Долгую сборку оставить в отдельной службе с одним заданием/ядром;
сообщить срок повторной проверки 3–5 минут. Возврат:
sudo nixos-rebuild switch --rollback. Личные настройки сохраняются.

## Ход выполнения

Исправление зафиксировано в 5b42c3f. Готовый пакет:
/nix/store/5gsf08bz3k6q5898b3m8vr30qf2d2p8v-doublecmd-1.2.9.
Собрана только обёртка и отсутствовавший UnRAR 7.3.1; исходный
Double Commander 1.2.9 остался прежним.

Через настоящие функции установленного unrar.wcx воспроизведён
OpenResult=15 до добавления библиотеки — тот самый код ошибки
«Не удалось открыть существующий файл». После исправления тот же
модуль прочитал и распаковал открытый проверочный RAR5 из тестов
libarchive (109 байт); содержимое helloworld.txt совпало с ожидаемыми
29 байтами. Проверялся API WCX с его UTF-16-строками, а не только
командная утилита. Пользовательский архив открыт для чтения заголовков,
подтверждён флаг шифрования, размер и время изменения сохранились.
Его содержимое не распаковывалось: пароля у проверки нет.

Отдельный реальный процесс Double Commander запускался без окна,
с собственными настройками и именем экземпляра. Из его окружения
проверены libunrar, libssh2_init(0)=0 и адрес существующего агента SSH.
Проверочный процесс завершён отдельно; пользовательские процессы
принудительно не закрывались. Итог: verification.json в каталоге задачи.

Сборка и применение main выполняются службой
nixos-doublecmd-rar-update.service. После применения повторяются
проверка процесса и модуля RAR, сравнение режимов мониторов и PID агента.
До завершения этой службы установка не считается подтверждённой.

Проверочный архив:
https://github.com/libarchive/libarchive/blob/master/libarchive/test/test_read_format_rar5_stored.rar.uu.
