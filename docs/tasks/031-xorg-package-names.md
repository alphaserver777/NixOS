# Современные имена библиотек X11

Состояние: выполнено. Дата: 14 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, задачи 002, 003 и 026.

## Причина и цель

В закреплённом nixpkgs устарели имена xorg.libX11, xorg.libXext,
xorg.xcbutil и остальные библиотеки из этой группы. Их использует
локальная упаковка Ассистента и Happ, что создаёт повторные предупреждения
при вычислении общей конфигурации. Перейти на новые имена без изменения
библиотек и поведения программ. Строка structuredAttrs is enabled
является информацией сборки и не требует исправления.

## Область

Изменить только ссылки на библиотеки в packages/assistant.nix и
packages/happ.nix и параметры функции Happ. Источники программ, версии,
контрольные суммы, способы запуска и закреплённые зависимости не менять.
Общие пакеты затрагивают машины, на которых включены соответствующие
модули. Не применять остальные накопившиеся изменения системы.

## Проверка

- [x] До и после изменения совпадают drvPath Ассистента и Happ.
- [x] Вычисление этих пакетов проходит без предупреждений xorg.
- [x] В локальной конфигурации отсутствуют ссылки на устаревшую группу.
- [x] Изменение зафиксировано, результат записан.

## Возврат и применение

При совпадении drvPath пересборка и применение не нужны: результат
идентичен прежнему, предупреждения исчезнут при следующем вычислении.
Для возврата восстановить два исходных файла из предыдущего изменения.
Полную текущую сборку пользователя не останавливать.
