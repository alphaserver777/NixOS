# Окно открытия и сохранения KDE

Состояние: выполнено.

Прочитаны WORKFLOW, constitution, architecture, devplan, DEPLOYMENT,
PROCESS и связанные задачи 010–011. Пользователь выбрал готовое окно KDE
для открытия и сохранения файлов. Работа в main по его прежнему указанию.

Цель: приложения, использующие системный выбор файлов, открывают окно KDE,
оформленное в действующую тёмную тему. Double Commander остаётся единственным
штатным файловым менеджером и обработчиком «Показать в папке».

Область: отдельный модуль NixOS рабочего стола для портала выбора файлов.
Добавляются KDE и GTK как запасной обработчик; FileChooser назначается KDE.
Остальные операции продолжают использовать Hyprland и GTK, как прежде.
Qt6-тема и русский язык задаются только службе KDE; остальные приложения
и язык системы сохраняются. Канал пакетов, stateVersion и личные данные
не меняются. Проверяется x-disk; другие физические машины не применяются.

Дополнение пользователя: оставить только Double Commander. Проверены пакеты
и пункты запуска рабочей машины: других файловых менеджеров уже нет после
задачи 010. Удаляются оставшиеся неиспользуемые модули PCManFM и Ranger,
а также устаревшее сокращение r для отсутствующего Ranger. Серверные
настройки не применяются; архиватор File Roller сохраняется как архиватор.

Проверка локально по данному пользователем указанию; до применения сборка
и фиксация изменений. Сохранение проверяется на специально созданной папке,
а не на личном документе. Проверка передачи выбранного пути, отмены,
открытия существующего файла, оформления, прежнего ShowItems и служб.
