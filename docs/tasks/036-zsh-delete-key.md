# Исправление Delete и проверка клавиш Zsh

Состояние: выполняется. Дата: 2026-10-25.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT; проверен действующий общий модуль Zsh и задача 035.
Работа продолжается в fix/main-display-clarity на основе b4e06fc.

## Проблема

Пользователь проверяет памятку сочетаний клавиш и сообщает: Delete
печатает ~ вместо удаления. В интерактивной Zsh с реальным терминалом
подтверждено: основная таблица emacs, ^[[3~ назначено undefined-key,
terminfo[kdch1] равно той же последовательности. Это ошибка назначения
клавиши в Zsh. Назначения терминала Alacritty и Tmux не меняются.

Проверенные назначения остальных клавиш:
Tab=expand-or-complete, ↑=atuin-up-search, ↓=down-line-or-history,
Ctrl+R=atuin-search, Ctrl+A/E=beginning/end-of-line,
Ctrl+U=kill-whole-line, Ctrl+K=kill-line,
Ctrl+W=backward-kill-word, Ctrl+L=clear-screen,
Ctrl+D=delete-char-or-list. Ctrl+C обрабатывается как прерывание
терминалом/оболочкой. Ctrl+D завершает оболочку только на пустой строке;
в непустой строке удаляет символ или вызывает список дополнений.

## Изменение

В существующем последнем блоке initContent общего
home-manager/modules/zsh.nix, после дополнений:

- привязать стандартный Delete (^[[3~) к delete-char;
- дополнительно прочитать последовательность Delete из terminfo
  и назначить её, если она существует;
- назначить Ctrl+U на backward-kill-line, чтобы соответствовать
  памятке пользователя (удалять от курсора до начала, сохраняя хвост).

Сохранить Atuin, поиск и историю, Tab, Ctrl+D и перемещение по словам.
Не менять shell history, личные сеансы Tmux и открытые терминалы.
Общий Home Manager используется домашними конфигурациями всех машин;
отдельный старый серверный профиль skel/.zshrc не переписывать в рамках
исправления рабочего окружения. Применить только на main.

## Проверка

- [ ] До изменения воспроизвести симптом в отдельном псевдотерминале
      безопасной строкой, без исполнения пользовательских команд.
- [ ] Проверить Delete в середине и конце строки, Backspace, Ctrl+U/K,
      Ctrl+A/E/W/L, Tab, стрелки и сохранение назначения Ctrl+R.
- [ ] Проверить обычные значения TERM: alacritty, xterm-256color,
      screen-256color, tmux-256color, linux и отсутствие kdch1.
- [ ] Проверить конфигурацию, собрать main, зафиксировать до применения,
      сохранить поколение, ядро и драйвер; не перезапускать сеанс.
- [ ] Проверить назначения в новой интерактивной Zsh после установки.

Для проверки использовать отдельные временные файлы истории и
управляемый псевдотерминал; не отправлять клавиши в терминал пользователя.
Долгую сборку оставить отдельной службе, сообщить срок 3–5 минут.

## Возврат

Сохранить текущее поколение в ~/.local/state/zsh-delete-20261025/previous-system.
Возврат: sudo nixos-rebuild switch --rollback. Открытые оболочки сохраняют
старые назначения до нового запуска. Для немедленного исправления
текущей оболочки допустима ручная команда bindkey '^[[3~' delete-char;
файлы пользовательских настроек при этом не изменяются.
