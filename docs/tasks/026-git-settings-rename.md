# Переименование параметров Git

Состояние: выполнено. Дата: 13 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, TEMPLATE и задача 017.

## Причина и цель

Home Manager 26.05 предупреждает о userName, userEmail и extraConfig.
Перенести общую настройку Git в programs.git.settings, сохранив значения.

## Область и ограничения

Изменяется только home-manager/modules/git.nix, общий для домашних
окружений всех шести машин. Системные параметры и список изменений
Home Manager не менять. 390 непрочитанных сообщений — уведомление.

## Действия

Поместить имя и адрес пользователя в settings.user, а содержимое
extraConfig — непосредственно в settings.

## Проверка

- [x] Настройки всех домашних окружений совпадают до и после изменения.
- [x] Вычисление новых настроек проходит без предупреждений Git.
- [x] Сформированный файл Git на main совпадает с применённым.

Вычислить programs.git.settings через nix eval для homeConfigurations;
сравнить JSON до и после. Проверить сформированный xdg.configFile
git/config и текущий файл пользователя. При совпадении повторное
применение ради переименования не требуется.

## Возврат

Вернуть прежнее содержимое git.nix из предыдущего изменения Git.
Значения настройки и файлы пользователя при миграции не меняются.

## Результат

JSON для всех шести homeConfigurations до и после совпадает.
В журнале вычисления после миграции предупреждений Git нет;
сравнение сформированного файла с ~/.config/git/config успешно.
Журналы сохранены в ~/.local/state/clash-git-recovery-20261013.
Сборка и повторное применение не требуются: содержимое файлов прежнее.
