# Приложение с окном для Codex из nixpkgs

Состояние: выполнено. Дата: 28 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, DEPLOYMENT,
PROCESS, задачи 030, 041 и 046; инструкция openai-docs и официальная
документация установки приложения на Linux.

## Цель и область

Пользователь явно выбрал отдельное приложение с окном. Расширение Codex
в VS Code уже есть; отдельная команда для терминала не является целью.
В официальном приложении Linux Codex входит в ChatGPT. Использовать
готовый пакет chatgpt из современной ревизии nixpkgs.
NixOS официально не заявлена среди поддерживаемых систем, поэтому
совместимость нужно проверить локальным запуском.

Добавить отдельное закрепление nixpkgs-chatgpt для готового пакета:
в общем закреплённом наборе chatgpt ещё поддерживает только macOS,
в современной ревизии уже есть Linux. Оставить комплектный CLI
штатной настройкой пакета codex=null. Получить значок и команду chatgpt.
Объявить установку через Home Manager для рабочих машин. Применять только
текущую x-disk. Настройки, сохранённые сеансы и данные входа ~/.codex
не читать и не менять; расширение VS Code и открытые приложения сохранить.
Общие каналы, ядро и сетевые службы не обновлять. В flake.lock добавить
только новое закрепление; существующие записи должны остаться прежними.
Долгие загрузки и сборки выполнять в фоне одним заданием и одним ядром.

## Применение и возврат

Перед применением сохранить путь текущей системы и пользовательского
профиля в ~/.local/state/codex-desktop-20261028. Проверить план применения
Home Manager: не применять накопившиеся изменения VPN, панели и буфера
обмена из других задач. Допустима отдельная установка собранного пакета
в пользовательский профиль Nix вместе с объявлением в Home Manager;
это даёт доступ сейчас и сохраняет приложение после обычной пересборки.
Для возврата удалить только установленный пакет из профиля и его
объявление, не удаляя настройки и историю приложения.

## Выбор пакета

В общих закреплённых nixpkgs пакет codex предназначен для терминала,
chatgpt — только для aarch64-darwin. Установленное расширение VS Code
не является отдельным приложением рабочего стола. Проверка современной
ветки nixos-unstable подтвердила готовую упаковку Linux, включая исправление
определения glibc в Electron и изменяемое сохранение комплектных модулей.
Поэтому собственный рецепт упаковки удалён, используется готовый рецепт
без местных исправлений его исходников.

flake.lock подтверждает совпадение всех прежних записей и входов.

Комплектный CLI сохранён штатным параметром codex=null.

Сборка завершена в пользовательской службе codex-desktop-native-build.
Каталог материалов: ~/.local/state/codex-desktop-20261028,
файлы build.status, build.log и ссылка package. Сборка требует четырёх
производных результатов и готовых зависимостей из двоичного хранилища;
полная сборка системы не запускалась. Код завершения сборки — 0.

Профиль пользователя имеет формат Nix profile версии 3, поэтому для
отдельной установки использовать nix profile add/install, не nix-env.
Профиль содержит foremost, home-manager-path, p7zip, poppler_utils,
testdisk; сохранить все пять записей. XDG_DATA_DIRS графического сеанса
включает ~/.nix-profile/share. Текущий обработчик HTTPS — Google Chrome.
Приложение установлено отдельно в этот профиль, без применения остальных
изменений Home Manager. Прежние пять записей профиля совпадают до и после,
добавлена только chatgpt. Системное поколение осталось прежним.
