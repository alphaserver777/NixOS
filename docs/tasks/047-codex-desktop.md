# Приложение с окном для Codex

Состояние: выполняется. Дата: 28 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, DEPLOYMENT,
PROCESS, задачи 030, 041 и 046; инструкция openai-docs и официальная
документация установки приложения на Linux.

## Цель и область

Пользователь явно выбрал отдельное приложение с окном. Расширение Codex
в VS Code уже есть; отдельная команда для терминала не является целью.
В официальном приложении Linux Codex входит в ChatGPT. Выпуск пакета
26.1023.51421 из официального репозитория, архитектура amd64.
NixOS официально не заявлена среди поддерживаемых систем, поэтому
совместимость нужно проверить локальным запуском.

Добавить воспроизводимый пакет Nix из официального .deb с закреплёнными
версией, адресом и SHA256, зависимости запуска, значок и команду chatgpt.
Объявить установку через Home Manager для рабочих машин. Применять только
текущую x-disk. Настройки, сохранённые сеансы и данные входа ~/.codex
не читать и не менять; расширение VS Code и открытые приложения сохранить.
Обновление канала, flake.lock, ядра и сетевых служб в задачу не входит.
Долгие загрузки и сборки выполнять в фоне одним заданием и одним ядром.

## Проверка

- [ ] Официальный пакет загружен, его контрольная сумма совпадает
  с записью репозитория OpenAI.
- [ ] Пакет Nix собирается, исполняемые файлы и библиотеки совместимы.
- [ ] В меню есть значок, окно запускается без отключения защиты Chromium.
- [ ] Пользователь может войти в аккаунт и выбрать Codex.
- [ ] Изменения, результат установки и ограничения проверки записаны.

## Применение и возврат

Перед применением сохранить путь текущей системы и пользовательского
профиля в ~/.local/state/codex-desktop-20261028. Проверить план применения
Home Manager: не применять накопившиеся изменения VPN, панели и буфера
обмена из других задач. Допустима отдельная установка собранного пакета
в пользовательский профиль Nix вместе с объявлением в Home Manager;
это даёт доступ сейчас и сохраняет приложение после обычной пересборки.
Для возврата удалить только установленный пакет из профиля и его
объявление, не удаляя настройки и историю приложения.
