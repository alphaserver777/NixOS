# Задача 055: космическая заставка загрузки Plymouth

## Контекст и статус

В работе. 2026-11-19 пользователь подтвердил установку Plymouth из коллекции
adi1090x/plymouth-themes. Прочитаны WORKFLOW, constitution, architecture,
devplan, PROCESS, DEPLOYMENT и задача 050; проверены boot.nix, исходники
модуля Plymouth и готового пакета закреплённого nixpkgs.
На x-disk используется systemd-boot, initrd systemd, видеодрайвер i915.
Plymouth пока выключен. На разделе /boot свободно около 287 МБ.

## Цель и изменение

Добавить отдельный nixos/modules/plymouth.nix в общий набор рабочих машин.
Использовать готовый пакет adi1090x-plymouth-themes с единственной темой
hud_space (119 кадров, около 3,6 МБ). Включить штатный модуль Plymouth,
приглушить текстовые сообщения на экране загрузки, сохранить доступ к
сообщениям через Esc и прежние поколения в меню systemd-boot.
Для проверенных Intel x-disk/Huawei загрузить существующий i915 в initrd
раньше: версия драйвера и ядро сохраняются. Другим машинам этот модуль
видеокарты не навязывать. На серверных наборах без общего рабочего стола
заставку не включать.

## Границы и безопасность

Обои, экран входа, блокировка, DMS и зависимости flake.lock не меняются.
Непроверенная задача 054 находится только в develop: в main переносить
только файлы задачи 055, сборку выполнять из main, чтобы не включить
незавершённое изменение клавиатуры. Текущий рабочий сеанс не переключать.
Для установки использовать nixos-rebuild boot: новый экран появится
при следующей обычной перезагрузке, которую пользователь выполняет сам.

## Проверка

- [x] Готовая тема собрана, просмотрен реальный кадр, размер 3,6 МБ.
- [ ] Вычислены настройки Huawei/main/x-disk и область серверных изменений.
- [ ] Собраны initrd и система x-disk из зафиксированного main.
- [ ] В initrd присутствуют Plymouth, тема и правильные пути к изображениям.
- [ ] Ядро/версия драйвера сохранены; размер загрузочных файлов помещается в /boot.
- [ ] Новое поколение записано для следующей загрузки, прежнее доступно.
- [ ] /run/current-system и работающий рабочий сеанс сохранены.

Фактическое отображение на физических мониторах проверяется пользователем
при следующей загрузке; сборка не заменяет эту проверку. Не перезагружать
компьютер и не запускать plymouthd поверх пользовательского сеанса.

## Применение и возврат

Материалы: ~/.local/state/plymouth-055. Сохранить прежнюю систему,
список поколений и загрузочные записи. Собирать в отдельной службе,
max-jobs=1, cores=1; при долгой сборке сообщить, через сколько продолжить.
Перед nixos-rebuild boot сравнить ядро, модули, ядровые параметры и службы;
ожидаются только Plymouth, ранняя загрузка i915 и тихий показ сообщений.
При нежелательном результате выбрать прежнее поколение в systemd-boot;
для постоянного возврата снова выполнить nixos-rebuild boot --store-path
с сохранённой прежней системой. Историю поколений и старые файлы не удалять.
