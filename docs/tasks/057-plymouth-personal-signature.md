# Задача 057: Black HUD с анимированной подписью

## Контекст и статус

В работе. Прочитаны WORKFLOW, constitution, architecture, devplan,
DEPLOYMENT, PROCESS и задачи 055–056. Пользователь выбрал пример
https://raw.githubusercontent.com/adi1090x/files/master/plymouth-themes/previews/6.gif
(Black HUD) и попросил подпись Vadim Moiseenko с появлением и исчезновением.

## Цель и область изменений

Заменить только тему Plymouth на Black HUD из закреплённого пакета Nixpkgs.
Под анимацией разместить VADIM MOISEENKO шрифтом Anurati, уже используемым
для часов. Этот шрифт имеет только прописные буквы. Подпись — отдельный
элемент Plymouth, её прозрачность плавно меняется в такт циклу кадров.
Типографское изображение строится однократно при сборке, дополнительные
процессы и обработка изображений при загрузке не нужны.

Общий модуль действует на том же наборе графических конфигураций.
Ядро, драйверы, экран входа, блокировка, рабочий стол и задача 054 не меняются.
Сохраняются читаемые штатные запросы пароля и диагностические сообщения.
Переход к входу не задерживается ради завершения анимации.

## Изменения

- packages/plymouth-personal.nix: выбранная готовая тема и подпись.
- packages/plymouth-signature.py: построение чётких букв с интервалами.
- packages/plymouth-signature.script: отдельный элемент и плавная прозрачность.
- nixos/modules/plymouth.nix: подключение личной темы.
- docs/architecture.md: описание и подтверждённый результат.

## Проверка

- [ ] Собрана только Black HUD, присутствуют все 164 исходных кадра.
- [ ] Подпись читаема; её размеры ограничены доступным местом на экране.
- [ ] Плавная прозрачность проверена на границах и внутри цикла.
- [ ] Тема испытана в изолированной виртуальной машине до записи на x-disk.
- [ ] Вычислены настройки всех шести хостов; серверы не получают новые службы.
- [ ] Система собрана из зафиксированной версии main без задачи 054.
- [ ] В initrd присутствуют тема, подпись и прежние необходимые компоненты.
- [ ] Ядро, модули и пользовательское окружение совпадают с поколением 290.
- [ ] Следующая загрузка подготовлена; текущий сеанс и старые поколения сохранены.

Физическое отображение оценивает пользователь после самостоятельной
перезагрузки. Это отдельная проверка, которую сборка не подменяет.

## Применение и возврат

Сборка в отдельной службе с одним заданием и низким приоритетом. При долгой
сборке сообщить, когда продолжить. Материалы: ~/.local/state/plymouth-057.
Запись только командой nixos-rebuild boot из зафиксированной версии main,
после проверки. Не перезагружать и не запускать Plymouth поверх сеанса.
До записи сохранить /run/current-system и профиль системы. Возврат через
сохранённое поколение 290 (предыдущая заставка) или 289 (до Plymouth).
Не закреплять номер поколения в переменных UEFI: выбор задаёт loader.conf.
