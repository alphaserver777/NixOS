# Задача 051: Navi и tldr

## Контекст и статус

Выполнено. Пользователь попросил установить Navi и tldr. Контекст:
WORKFLOW.md, constitution.md, architecture.md, devplan.md, DEPLOYMENT.md,
PROCESS.md, задачи 050/036, текущие Zsh, Fzf и Atuin изучены.

## Цель и область

Общий модуль Home Manager устанавливает Navi и Tealdeer (команда tldr).
Navi получает русские описания команд NixOS, Git, Docker, SSH и файлов,
пользовательский каталог дополнений и Ctrl+G для вставки в строку Zsh
перед выполнением. Обычный вызов navi в Zsh также подставляет выбранную
команду в следующую строку ввода. Аргументы командной строки передаются
готовому приложению без изменения, в том числе из его штатного дополнения.
Ctrl+R Atuin и остальные назначения сохраняются. tldr предпочитает
русский перевод и затем английский, обновляет справочник при обращении,
без отдельного постоянно работающего процесса.

## Применение и возврат

Сначала фиксировать исходники. Установить готовые пакеты в современный
пользовательский профиль Nix без замены существующих записей; применить
только созданные Home Manager файлы Navi/Tealdeer/Zsh. Сохранить прежние
ссылки и сведения о профиле в ~/.local/state/command-cheatsheets-051.
После установки обновить справочник tldr. Не выполнять команды из подборки
и не перечитывать настройки внутри открытых терминалов пользователя.
Для постоянного применения при загрузке включить изменение в системную
сборку задачи 050. До её применения честно различать готовность текущего
сеанса и нового системного поколения.
Возврат: восстановить прежние ссылки, убрать только добавленные записи
профиля и отменить изменение модуля. Историю команд и личные шпаргалки
не удалять. Перезагрузка для текущего сеанса не требуется.

## Результат

2026-11-13: Huawei/main/x-disk вычисляют Navi 2.24.0 и Tealdeer 1.8.1,
языки ru/en. Установлены готовые пакеты Nix и четыре результата Home Manager:
настройки Navi, Tealdeer, каталог пяти подборок и .zshrc. В подборках
35 команд. Поиск русского описания с --print/--best-match возвращает
`git status --short --branch`, сама команда не выполнялась.
Синтаксис .zshrc проверен, сравнение со старым файлом показало только
добавление Navi. В отдельном терминале с TERM=xterm-256color проверены
Ctrl+G=_navi_widget и Ctrl+R=atuin-search. В терминале TERM=dumb Zsh
отключает редактор строки, поэтому штатное дополнение там не подключается.
tldr --update скачал ru/en, `tldr --language ru tar` показал русские примеры.

Собрано и применено системное поколение из исходников 9879263:
/nix/store/y7b1w0lb0bq4v2q2hb2988ddflpyk407-nixos-system-x-disk-26.05.20261006.b253099.
Ядро, модули, параметры загрузки, modprobe и udev совпали с прежним
поколением, из системных служб изменён только home-manager-admsys.
Активация завершилась сообщением Done, /run/current-system указывает на
новое поколение, служба Home Manager активна. Ошибка записи кода завершения

переключения и на активацию не повлияла; итог дополнительно проверен.

пуст. Оформление задачи 050 также закреплено этим поколением.
