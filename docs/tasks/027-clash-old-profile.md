# Старая копия Clash в пользовательском профиле main

Состояние: выполнено. Дата: 13 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, TEMPLATE и задача 017.

## Причина и цель

Меню запускает ~/.nix-profile/bin/clash-verge версии 2.2.3.
В системе уже установлен Clash 2.4.7, управляемый модулем
nixos/modules/clash-verge.nix. У старой копии падает WebKitWebProcess
с SIGABRT; пользователь видит прозрачное окно. Прямой запуск системной
версии показывает заполненное непрозрачное окно.

## Область и ограничения

Только пользовательский профиль main: удалить отдельно установленную
старую копию Clash. Прочие пакеты, настройки VPN, подписки, службу
clash-verge-service и конфигурацию других машин сохранять.
Новых настроек прозрачности и переменных графического движка не нужно.

## Действия

Сохранить сведения о предыдущем профиле и его перечень пакетов в
~/.local/state/clash-git-recovery-20261013; выполнить
`nix profile remove clash-verge-rev`. Настройка установки актуального
Clash уже зафиксирована в репозитории и применена системой.

## Проверка

- [x] Прямой запуск Clash 2.4.7 показывает непрозрачное заполненное окно.
- [x] Команда clash-verge разрешается в системный пакет 2.4.7.
- [x] В профиле сохранены home-manager-path и nodejs_22.
- [x] Системная служба Clash активна, новых падений WebKit нет.

Проверить command -v и readlink -f, nix profile list --json,
systemctl status clash-verge-service и журнал проверочного запуска.
Повторный запуск из меню пользователь подтверждает отдельно.

## Возврат

Вернуть только старый пакет:
`nix profile install /nix/store/iqndjc2n4xj00gfylbxvb6kp7ab8m23n-clash-verge-rev-2.2.3`.
Старую версию не запускать параллельно с новой. Возврат старого пакета
может вернуть исходную ошибку.

## Результат

Удалён только элемент clash-verge-rev. Остальные элементы профиля
проверены сравнением JSON и полностью сохранены. Команда теперь ведёт
в /run/current-system/sw/bin/clash-verge, пакет 2.4.7.
Проверочный запуск clash-current-check.service активен; окно оставлено
открытым. Снимок окна показывает непрозрачный фон и заполненный
интерфейс. WebKit 2.54.1 продолжает работать, новых падений нет.
Системная служба Clash активна; ошибок Hyprland и отказавших служб нет.
Результат повторного запуска непосредственно из меню пока не проверен.
