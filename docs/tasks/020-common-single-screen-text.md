# Общий выбор одного экрана для блокировки и заставки

Состояние: выполняется. Дата: 10 октября 2026 года.

Контекст WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT и задачи 018, 019 прочитан. Пользователь уточнил, что
такое оформление нужно и на x-disk с другими мониторами.

## Изменение

Заменить привязку к имени HDMI-A-1 общим выбором подключённого экрана:
сначала экран в точке 0,0, затем активный, затем первый доступный.
На нынешнем main это выбранный GIGABYTE; на x-disk — основной экран.
Названия разъёмов и модели не закреплять в новом выборе.

Применить общий выбор к часам заставки и всем надписям/полю пароля
Hyprlock. Фон блокировки и анимация заставки остаются на всех экранах.
Сопоставлять выход Hyprland с GTK по координатам, а не индексу.
Заставка повторяет выбор при подключении/отключении экрана.

Hyprlock перед запуском получает временную копию управляемой настройки
с выбранным экраном. Запускается настоящий Hyprlock, настройки PAM,
проверка пароля и параметры блокировки сохраняются. При ошибке запроса
мониторов запуск блокировки продолжается с надписями на всех экранах.
Явно переданная пользователем сторонняя настройка Hyprlock не меняется.
Не блокировать работающий сеанс ради проверки.

## Область и проверка

Общие модули Home Manager: main, x-disk, Huawei. Вычислить настройки
всех трёх; локально собрать и применить только main. Остальные машины
получат изменение при следующем применении их конфигураций.

- [x] Проверка выбора при разных именах, порядке и числе экранов.
- [x] Проверка, что ошибки запроса не отменяют запуск Hyprlock,
      а явные --config, --help и --version сохраняют поведение.
- [ ] Вычисление общей настройки main, x-disk, Huawei.
- [ ] Сборка и применение main, исправные службы и DMS.
- [ ] Часы только на выбранном экране, фон на всех.
- [ ] Пользователь подтверждает вид при следующей блокировке.

## Применение и возврат

Исходное поколение 149. Проверить план, ядро, версию, настройки модулей
перед автоматическим применением. Допускается только перезапуск
Home Manager; другие действия в плане останавливают применение.
Сборка и применение в отдельной службе с сохранёнными журналами.
Возврат: sudo nixos-rebuild switch --rollback. Старые поколения сохранены.

## Результат предварительной проверки

Проверены разные разъёмы, другой порядок перечисления, один экран,
отключённый основной экран и отсутствие экрана в точке 0,0.
На реальной управляемой настройке меняются только шесть привязок
надписей/поля пароля, блок фона сохраняется полностью.

Запуск проверен с подставным исполняемым файлом без настоящей блокировки:
сохраняются параметры --grace и код завершения настоящего процесса,
--config, --help и --version передаются без запроса мониторов.
При отказе запроса запускается процесс с надписями на всех экранах.
Рабочая копия настройки имеет права 600. Исходная настройка также
остаётся допустимой при прямом запуске Hyprlock без обёртки.
