# Восстановление пользовательского окружения main после обновления

Состояние: выполнено. Дата: 10 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, TEMPLATE и задача 014. Продолжается обновление main;
задача 009 этого обновления находится в ветке fix/nvidia-linux-7-2.
В текущей ветке main номер 009 уже занят другой задачей.

## Причина

Загружено поколение 146: NixOS 26.05, ядро 7.2.9-zen1.
Home Manager остановился при замене темы Kvantum: прежняя ссылка
на весь каталог Base16Kvantum ведёт в неизменяемое хранилище Nix,
а новое поколение управляет отдельными файлами внутри каталога.
Из-за прерванного применения Hyprland использует старую настройку
и сообщает о 21 ошибке: pseudotile, workspace_swipe, togglesplit,
windowrulev2. В подготовленном пользовательском поколении эти настройки
уже заменены поддерживаемыми.

Отдельная служба wayland-to-x11-clipboard, созданная вручную 6 июля,
пытается запускать отсутствующий ~/.nix-profile/bin/wl-paste каждые
две секунды. Установленные программы доступны через
/etc/profiles/per-user/admsys/bin.

## Действия

Сохранить прежнюю ссылку Kvantum вне пути управляемых файлов,
повторно запустить существующую службу Home Manager, перечитать
настройку Hyprland. Остановить старую службу буфера обмена и перенести
её настройку в Home Manager с путями к установленным пакетам Nix.
Новую настройку вручную в ~/.config не создавать.

Восстановление использует уже собранное и зафиксированное поколение.
Текущая ветка main содержит последующие изменения других машин
и вновь подключает фирменный NVIDIA; целиком на main её не применять.
Для исправления службы использовать отдельное рабочее дерево
`/home/admsys/Nixos-main-recovery`, ветка `fix/nvidia-linux-7-2`,
с конфигурацией установленного поколения 146. Собирать и применять
только этот вариант main. Ядро, драйвер и другие машины не менять.

## Проверка

- [x] Home Manager завершает применение успешно.
- [x] hyprctl configerrors не возвращает ошибок.
- [x] Нет неисправных системных и пользовательских служб.
- [x] Прекратились повторные ошибки запуска wl-paste.
- [x] Сохранены три экрана; служба буфера запускается без ошибки пути.

## Возврат

Прежнее системное поколение 145 доступно в загрузочном меню.
Старую ссылку темы сохранить в ~/.local/state/main-recovery-20261010.
Для возврата ссылки сначала остановить применение Home Manager,
сохранить новую раскладку файлов и вернуть прежнюю ссылку.
Ручную службу буфера сохранить перед заменой. При возвращении её
исходного содержимого ошибка пути вернётся.

## Результат восстановления

Ссылка темы сохранена в указанной папке. Повторное применение службы
Home Manager успешно; hyprctl configerrors пуст. Системных и
пользовательских отказавших служб после восстановления нет, доступны
HDMI-A-1, DVI-D-1, DP-1. Ручная служба буфера остановлена на время
замены; её исходный файл также сохранён в папке восстановления.

В hosts/main/clipboard.nix создана настройка Home Manager с прямыми
путями к wl-paste и xclip, запуском только в графическом сеансе.
Она включена в main в обеих ветках; для сборки используется
зафиксированный dab01b8 в fix/nvidia-linux-7-2. Сборка выполняется
как пользовательская служба nixos-main-recovery-build.
Журнал и состояние: ~/.local/state/main-recovery-20261010/build.log,
build.state, build.status. Сборка и применение завершились с кодом 0.
Установлено поколение 147:
`/nix/store/c1ys1l6i9qm8bm5rmhgy0pppv575l07y-nixos-system-main-26.05.20261006.b253099`.
Служба буфера активна, ExecMainStatus=0, NRestarts=0. Home Manager
успешно применён; ошибок Hyprland и неисправных служб нет.

После получения новых изменений номер этой задачи изменён с 015
