# Задача 056: снять старое закрепление поколения в UEFI

## Контекст и статус

Выполнено. При проверке задачи 055 обнаружено: /boot/loader/loader.conf
выбирает nixos-generation-290.conf, но bootctl status показывает
поколение 235 загрузкой по умолчанию. В JSON bootctl list запись 235
имеет isDefault=true, хотя текущий сеанс работает из поколения 289.
Это согласуется с прежними сообщениями пользователя о возвращении
старого рабочего стола после перезагрузки.

## Изменение и безопасность

После проверки новой загрузочной записи снять только сохранённое
закрепление LoaderEntryDefault командой `bootctl set-default ""`.
Штатный выбор далее задаёт loader.conf, обновляемый NixOS. Не фиксировать
поколение 290 в UEFI: иначе следующие обновления снова окажутся перекрыты.
Не менять порядок загрузочных устройств, таймер, старые записи или
однократные назначения. Перезагрузка не запускается.
