# Задача 058: понятный выбор команды из истории

## Статус

В работе. Прочитаны WORKFLOW, constitution, architecture, devplan,
PROCESS, DEPLOYMENT и задача 054.

## Цель и область

После Ctrl+R должно быть понятно, как найти, выполнить или исправить
увиденную команду. Изменяется существующий модуль Atuin и памятка клавиш.
Общий модуль используется окружениями, импортирующими atuin.nix;
применение сейчас только на main через Home Manager. Системная сборка,
синхронизация, содержимое пользовательской истории и tmux не меняются.

## Причина и решение

Стандартный полноэкранный список не объясняет способ выбора по цифрам.
Alt+цифра занят переключением окон tmux. Использовать штатные возможности
Atuin: окно высотой 18 строк, поиск и новые команды сверху, видимые
подсказки, Enter для выполнения, Tab для правки. При открытии включается
ввод Vim: можно сразу печатать запрос; Esc включает перемещение, цифра
подставляет строку с соответствующим номером для правки; Enter оболочки
выполняет подставленную команду. Ctrl+C отменяет поиск.
Ctrl+R оболочки в обычном режиме сохраняет повтор отменённого изменения.

## Проверка

- [x] На отдельной временной базе проверены Enter, Tab, Esc+цифра и отмена.
- [x] Проверены ввод запроса, новые команды сверху, подсказка и окно до 18 строк.
- [x] Проверена конфигурация Home Manager без применения.
- [ ] Зафиксировать изменения, применить на main, проверить установленные параметры.

## Возврат

Вернуть прежние параметры atuin.nix из коммита b5509e2 и применить
Home Manager. База истории не изменяется, восстановление данных не требуется.

Проверка установленным Atuin 18.15.2 выполнена в отдельном tmux без
пользовательских настроек, с временными базой и каталогом данных:
`/tmp/atuin-select-qjx5xw4l`. Выполнение подтверждено по возвращаемому
оболочке признаку `__atuin_accept__`; проверочные команды не исполнялись.
Обычный выбор по цифре возвращает команду без этого признака, как Tab.
