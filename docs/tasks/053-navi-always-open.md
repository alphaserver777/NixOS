# Задача 053: Ctrl+G всегда открывает поиск Navi

## Контекст и статус

В работе. Пользователь набирает git log, видит серую подсказку истории
и при Ctrl+G получает заполненную строку вместо списка Navi.
Прочитаны процесс и архитектура из контекста, задачи 051/052, текущие
Navi/Zsh и исходники zsh-autosuggestions. В Navi 2.24 штатное дополнение
использует --best-match при непустой строке; это немедленно выбирает
git log --oneline --graph --decorate -20 из нашей подборки.

## Изменение и границы

Оставить штатное дополнение Navi, при подключении удалить --best-match
из его текста. finder.overrides=--no-select-1 отключает также автоматический
выбор единственного совпадения. Ctrl+G открывает список с набранным запросом,
Enter подтверждает, Esc отменяет. История Atuin и Ctrl+R сохраняются.
Справочники, пакеты, конфигурация остального рабочего стола не меняются.

## Проверка

- [ ] Zsh синтаксически допустим, подключаемый сценарий без --best-match.
- [ ] В отдельном терминале Ctrl+G после git log открывает список.
- [ ] Единственное совпадение тоже требует выбора.
- [ ] Отмена сохраняет набранный запрос; команда не выполняется.
- [ ] Ctrl+R остаётся за Atuin, конфигурация применена и опубликована.

## Применение и возврат

Собрать и применить систему из коммита; проверить неизменность ядра,
параметров загрузки и системных служб кроме Home Manager.
При долгой сборке оставить отдельную службу и не ждать в чате.
Предыдущее поколение nskryil3kv3l7n7bx0vkazas07isi0dv сохранить;
возврат — nixos-rebuild switch --rollback.
Открытые терминалы автоматически не перечитывать. Пользователю сообщить,
что для текущей оболочки нужно выполнить exec zsh. Историю не очищать.
