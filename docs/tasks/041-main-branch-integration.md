## Действия и ограничения

Объединить origin/develop и fix/main-display-clarity в develop, затем
перевести main на общий результат. Сохранить ref=dev для OpenCode и
согласовать с ним original в flake.lock, сохранив закреплённую ревизию
и все остальные зависимости. Проверить результат относительно обеих
исходных веток и собрать NixOS main из зафиксированного изменения.
Применение системы и перезагрузка в эту задачу не входят.

Перед удалением веток сохранить и проверить полный архив git bundle
в ~/.local/state/nixos-main-integration-20261027T162131Z.
Удалять старые удалённые ветки только после проверки вхождения в main
и успешной отправки main. Сохранить постоянные main и develop.
Устаревшую локальную ветку восстановления сохранить в архиве, не
объединяя её старые настройки. Дополнительные рабочие каталоги убрать
только если в них нет незаписанных изменений.

git ls-remote после отправки; git status и git worktree list после очистки.
Долгую сборку оставить службе и предложить проверку через 3–5 минут.

## Возврат

Полный архив branches-before.bundle и refs-before.txt сохраняют исходные
ветки, включая старую локальную ветку восстановления. Восстановление:
git fetch /путь/branches-before.bundle refs/heads/ИМЯ:refs/heads/ИМЯ.
Установленная система не меняется, предыдущее поколение записано в
previous-system в том же каталоге. Для отмены опубликованных изменений
использовать отменяющий коммит, не принудительную отправку.
