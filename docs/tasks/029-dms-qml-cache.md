# Обновление сохранённого QML после изменения Sands

Состояние: выполнено. Дата: 13 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT и задача 028. Изучена документация Qt о QML Disk Cache.

## Причина и цель

После применения задачи 028 файлы Sands новые, но его окно старое.
Перечитывание расширения и перезапуск панели не помогают. Временный
запуск с QML_DISABLE_DISK_CACHE=1 показывает новый интерфейс.
Сохранённые QML-файлы содержат прежний текст TimerPanelContent.
Исключить использование старой сохранённой версии при обновлении Sands.

## Область и ограничения

В общей оболочке cosmic-dms установить QML_DISK_CACHE_PATH в каталог,
название которого включает путь собранного Sands. Применить только main.
Сохранение QML остаётся включённым; прежние данные не удалять.
Таймеры, история, настройки панели и режим запрета простоя сохраняются.

## Проверка

- [x] Отключение сохранённого QML устраняет воспроизведённую проблему.
- [x] Путь каталога меняется вместе с собранным Sands.
- [x] Временная настройка службы удалена, новая работает из Nix.
- [x] После применения отображается новый интерфейс, ошибок QML нет.

## Применение и возврат

Собрать main из зафиксированного изменения и проверить план, ядро,
драйвер. Ожидаются только Home Manager и служба cosmic-dms.
Предыдущее поколение сохранить; возврат: nixos-rebuild switch --rollback.
Временный файл /run/user/1000/systemd/user/cosmic-dms.service.d/
timer-cache-check.conf убрать до применения; сохранить его копию
в ~/.local/state/timer-duration-20261013.

Документация: https://doc.qt.io/qt-6/qmldiskcache.html.

## Ход работы

Отключение дискового сохранения показывает поле задачи 028; обычное
перечитывание расширения и перезапуск панели показывали старый вариант.
Название отдельного каталога в оболочке включает полный идентификатор
собранного Sands, поэтому при изменении его файлов меняются каталог
и оболочка запуска панели. Сохранение QML остаётся включённым.
Сборка и применение выполняются службой nixos-timer-layout-update,
материалы: ~/.local/state/timer-layout-20261013. Она убирает временную
настройку и восстанавливает запрет простоя, если он был включён.
