# Открытие текста и Markdown из файлового менеджера

Состояние: завершена техническая настройка. Дата: 2026-10-25.

Прочитаны и проверены WORKFLOW, constitution, architecture, devplan,
PROCESS, DEPLOYMENT; контекст задач 010, 011 и 038. Работа продолжается
в fix/main-display-clarity на основе 2982eb4.

## Проблема и цель

Пользователь сообщает, что txt не открывается в Double Commander,
и просит удобное открытие md. Проверено: text/plain по умолчанию
обрабатывает nvim.desktop с Terminal=true; text/markdown и
text/x-markdown не имеют явного обработчика. Внутреннего extassoc.xml
нет, поэтому Double Commander использует системные связи типов файлов.
VS Code и Obsidian установлены; первый поддерживает открытие отдельных
текстовых файлов и просмотр Markdown без создания хранилища заметок.

Задан необязательный вопрос о предпочтении редактора. Пока ответа нет,
используется уже установленный VS Code; предположение сообщено
пользователю до изменения. При поступлении ответа выбор уточнить.

## Изменение и область

Отдельный общий модуль home-manager/modules/document-openers.nix:

- установить VS Code в пользовательское окружение, чтобы обработчик
  всегда существовал на машинах, использующих общий Home Manager;
- создать собственный пункт запуска для текста и Markdown с абсолютным
  путём к code, --reuse-window и %F, Terminal=false;
- связать только text/plain, text/markdown, text/x-markdown с этим
  пунктом через xdg-mime в активации Home Manager;
- сохранить изменяемый mimeapps.list, браузер, изображения, папки,
  архивы и остальные назначения пользователя.

Просмотр Markdown включается пользователем через Ctrl+Shift+V;
не менять глобальные настройки редактора, расширения, рабочие папки
и хранилища Obsidian. F3/F4 во встроенном редакторе Double Commander
сохраняются. Применить на main, другие машины не обновлять удалённо.

подмену редактора, фиксирующую только аргументы проверочных файлов.
Открытие настоящего документа пользователем — отдельная оценка удобства.

## Применение и возврат

Материалы: ~/.local/state/text-markdown-openers-20261025.
Сохранить предыдущую систему и копию mimeapps.list перед применением.
Возврат системы: sudo nixos-rebuild switch --rollback; затем восстановить
только прежние назначения трёх текстовых MIME-типов из копии, поскольку
изменяемый файл не откатывается вместе с поколением автоматически.
Долгую сборку оставить отдельной службе; повторная проверка через 3–5 минут.

## Ход выполнения

вычислены параметры запуска и текст активации. На временных настройках

обработчик для .txt и .md с кириллицей и пробелами, пути переданы
отдельными аргументами без изменений. Настоящий VS Code при этой
проверке не запускался и личные документы не открывались.

запуска, наличие программы и сохранение прочих MIME-записей из копии.
До завершения этих проверок установка не считается подтверждённой.
