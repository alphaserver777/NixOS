# Задача 054: Vim и переходы с метками в командной строке

## Контекст и статус

В работе. Пользователь подтвердил настройку Vim и переходов с метками
в Zsh после обсуждения готовых решений. Прочитаны WORKFLOW, constitution,
architecture, devplan, DEPLOYMENT, PROCESS, задачи 051–053, текущие
Zsh/Navi/Atuin/Starship и исходники IngoMeyer441/zsh-easy-motion.

## Цель и область

Встроенный режим Vim Zsh: обычный ввод при начале команды, Esc для
перемещения, i/a для возврата к вводу, f/F, w/b и текстовые объекты.
Готовый zsh-easy-motion с закреплением ревизии и контрольной суммы:
пробел в режиме перемещения запускает выбор действия; s + символ
показывают метки в обе стороны, w — начала слов.
Курсор-полоска при вводе и блок при перемещении; цвет меток согласовать
с текущей темой. Ctrl+G Navi и Ctrl+R Atuin сохранить в обоих режимах;
Delete, Ctrl+U, Ctrl+стрелки и обычное редактирование в режиме ввода сохранить.
Новую командную строку всегда начинать с ввода. Escape не должен заметно
задерживаться. Проверить Alacritty/Tmux без изменения их конфигураций.

## Реализация и границы

Отдельный Home Manager модуль zsh-vim.nix, подключаемый после Navi.
Пакет готового дополнения содержит только исходники и закреплённый путь
к Python из Nix; установка через pip и фоновые процессы не нужны.
Чтение клавиш в Python исправить с однобайтового ASCII на UTF-8, сохраняя
быстро введённые последовательности. Navi перед вызовом получает полный
буфер; при отмене восстанавливается исходное положение курсора.
В режиме перемещения серые автоподсказки временно отключаются, чтобы
движения Vim не принимали текст из истории; ручной запрет подсказок сохраняется.
При настройке использовать add-zle-hook-widget, сохраняя хуки Starship.
Остальные программы, история, загрузчик и flake.lock не меняются.
Область — окружения, импортирующие общий home-manager/modules/default.nix.
Серверы без этого окружения автоматически не переводить в новый режим.

## Применение и возврат

До применения создать коммит. Собрать систему из него отдельно с одним
заданием и ядром; при долгой сборке сообщить время следующей проверки,
не ждать в чате. Проверить неизменность ядра, модулей, параметров загрузки
и системных служб кроме Home Manager. Предыдущее поколение
fx23rsawkb9zhni21r88pg8rj1k6130c сохранить для nixos-rebuild switch --rollback.
Тестировать только в своей отдельной оболочке, не перечитывать настройки
в открытых терминалах пользователя. После применения сообщить exec zsh
и короткую памятку по клавишам. Не выполнять проверочные команды из
редактируемой строки, не удалять историю.
