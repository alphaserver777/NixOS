# Выделение скачанного файла в Double Commander

Состояние: выполнено.

Прочитаны WORKFLOW, constitution, architecture, devplan, DEPLOYMENT,
PROCESS и задача 010. Работа продолжается в main по указанию пользователя.

Браузер открывает папку загрузок без выбора файла. В пользовательском
окружении нет обработчика org.freedesktop.FileManager1. Портал OpenDirectory
при его отсутствии передаёт только родительскую папку штатному приложению.

Цель: команда «Показать в папке» открывает Double Commander с курсором
на нужном файле. Добавляется небольшая пользовательская служба связи
FileManager1, передающая полный путь штатной команде Double Commander.
Проверяются русские имена, пробелы и специальные символы; оболочка для
обработки имён не используется. Удалённые адреса и несуществующие пути
отклоняются. ShowItemProperties возвращает явную ошибку неподдерживаемой
операции. Выбор и открытие самого файла остаются разными действиями.

Область: общий пользовательский модуль файлового менеджера рабочих машин.
Применение только x-disk. Настройки браузера, обработчики остальных типов
файлов, версия Double Commander, оформление и календарь сохраняются.
Проверка локально по ранее данному указанию пользователя; другие машины
недоступны. До применения выполняется сборка и фиксация изменений.

Проверка:

- [x] Служба отвечает на ShowItems и открывает полный путь без запуска файла.
- [x] Курсор перемещается на проверочный файл в существующем окне.
- [x] OpenDirectory портала также передаёт файл в службу.
- [x] Сборка, применение и службы рабочего стола работают.
- [x] Открытие папок и личные обработчики типов файлов сохранены.

Возврат: `sudo nixos-rebuild switch --rollback`, предыдущее поколение 272.
Служба удаляется возвратом модуля; пользовательские данные не меняются.

Источники:
https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.OpenURI.html
и https://doublecmd.github.io/doc/ru/commandline.html.
