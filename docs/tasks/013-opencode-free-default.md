# Бесплатная модель OpenCode по умолчанию

Состояние: в работе.

Прочитаны правила процесса, constitution, architecture, devplan, DEPLOYMENT
и задача 012. Пользователь просит разобраться, почему OpenCode здесь
работает иначе, чем в Ubuntu, и подтвердил, что выбран A6API.

Причина: личный файл ~/.config/opencode/opencode.json явно назначает
a6api/gpt-5.6-sol. Программа 1.18.30 уже поддерживает бесплатные модели
OpenCode; это не ограничение NixOS. Список бесплатных моделей доступен
без подключения аккаунта OpenCode. Прямой проверочный запрос к
space-bunny-free со штатным общедоступным значением public вернул HTTP 200
и OK; личные ключи и содержимое проектов не передавались.

Цель: новый запуск OpenCode выбирает бесплатную Space Bunny Free без
личного ключа. A6API и его сохранённые реквизиты остаются доступны вручную.
Версия программы и flake.lock не меняются.

Изменение: отдельный модуль Home Manager только x-disk, где установлен
OpenCode. Однократная замена основного выбора A6API и малой модели через
активацию; все прочие настройки сохраняются. Перед изменением локальная
копия с ограниченным доступом. Файл остаётся изменяемым. Последующий
ручной выбор пользователя не отменяется при пересборках.

Проверка:

- [ ] Основная и малая модели — opencode/space-bunny-free.
- [ ] Бесплатный ответ без личного ключа проверен.
- [ ] Раздел A6API и файл реквизитов не изменились.
- [ ] Повторная активация не меняет новый ручной выбор.
- [ ] Сборка и применение успешны; рабочий стол работает.

Возврат: копия ~/.local/state/nixos-opencode-free/config-before.json
в ~/.config/opencode/opencode.json; удаление маркера default-initialized
нужно только для повторного однократного применения. Откат поколения
возвращает конфигурацию модулей, личный выбор модели возвращается копией.
Копия и реквизиты не добавляются в Git.

Источники: https://opencode.ai/docs/zen/ и загрузчик моделей официального
исходного кода закреплённой версии OpenCode (provider/provider.ts).
Бесплатная доступность зависит от правил и ограничений службы OpenCode.
