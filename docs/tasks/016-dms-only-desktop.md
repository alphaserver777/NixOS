# DankMaterialShell как единственное оформление рабочего стола

Состояние: завершена.

Контекст прочитан в задаче 015: WORKFLOW, constitution, architecture,
devplan, PROCESS, DEPLOYMENT, задачи 012 и 015. Пользователь явно выбирает
нынешний DankMaterialShell, просит убрать старые варианты, вернуть значок
микрофона, объединить и отправить все изменения в main.

## Область

Рабочие столы общего Home Manager: только DMS 1.6.2 с выбранными
доработками. Применяется x-disk; другие физические машины и отдельное
серверное окружение server-hypr не применяются. Его Hyprpanel/wofi остаются
отдельной серверной конфигурацией, не входят в рабочий стол x-disk.
Задача 015 заменяется прямым запуском DMS; переключатель больше не нужен.

Удалить Noctalia, Hyprpanel, переключатель и пункты пробных оболочек из
рабочего окружения. Убрать Walker/Elephant, SwayNC и Wofi из desktop.
Для двух коротких списков режима и заставки использовать готовый диалог
Zenity, а основной поиск, буфер и уведомления обслуживает DMS.
Режим видео переводится на штатное управление запретом простоя DMS.
Предусмотреть прямой запуск DMS при каждом графическом входе и повторный
запуск при настоящем падении; не останавливать его по короткой проверке.
Вернуть штатный значок микрофона: состояние включения видно постоянно,
правый щелчок переключает звук. Сохранить прежнюю клавишу микрофона.

Настройки изменяемые: однократная миграция включает значок, сохраняя
личное размещение виджетов и значения остальных параметров. Сначала
копия настроек. Учётные данные, обои, блокировка, плагины и календарь
с данными не удаляются. Личные старые архивы панелей не чистить вслепую.

## Проверки

- [x] Сборка desktop проходит; вычисление остальных desktop проверяется.
- [x] В результирующем desktop нет старых панелей, служб переключения,
  дублирующего поиска и уведомлений.
- [x] DMS подключён к graphical-session.target и настроен на повторный запуск.
- [x] Значок микрофона включён, управление подтверждено через PipeWire,
  прежнее состояние микрофона восстановлено после проверки.
- [x] Панель, буфер, календарь, флаги, блокировка и заставки сохранены.
- [x] Применение из зафиксированного состояния прошло, изменения в main
  отправлены в origin/main, отказавших служб нет.

Сборка — одно задание и одно ядро, в фоне. Предыдущее поколение 280
сохранено в ~/.local/state/nixos-dms-only/previous-system. Новые
материалы — ~/.local/state/nixos-dms-only. Откат поколения не удаляет
личные данные; копия настроек позволяет отменить включение значка.
Проверить запущенный DMS перед перезапуском, не закрывать приложения.

## Результат проверки, 2026-10-10

Исходный код 9bbe218 собран и применён на x-disk, поколение 281:
`/nix/store/1jxsfs639s79v1nqcdskjzz195038p1z-nixos-system-x-disk-26.05.20261006.b253099`.
Обе операции завершились с кодом 0. На Huawei и main отдельно вычислены
параметры службы DMS: прямой запуск, WantedBy графического сеанса,
Restart=on-failure, список прежних служб пуст. Эти машины не применялись.

В текущем окружении нет команд cosmic-shell, cosmic-noctalia, hyprpanel,
walker, elephant, wofi, swaync. Старые службы удалены; DMS активен и
включён для последующих входов, число повторных запусков 0. Системных
и пользовательских отказавших служб нет; hyprctl configerrors пуст.

Миграция настроек проверена отдельно: сохраняет личные параметры и
исходную копию, повторный запуск не сбрасывает ручные изменения.
В применённых настройках глобальный и индивидуальный параметры значка
микрофона включены. Команда DMS audio micmute действительно выключила

микрофона присутствуют в итоговой конфигурации Hyprland.

Настройки размещения виджетов, буфера, календаря и оформления сохранены;

простоя и снимает только включённый им самим. Проверка блокировки и
заставки в этом сеансе ограничена сборкой и конфигурацией: принудительная
блокировка пользователю не навязывалась.

Слияние в main выполнено без конфликтов, код 9bbe218 отправлен в
origin/main. Предыдущие поколения для отката не удалялись.
Копия пользовательских настроек: ~/.config/DankMaterialShell/settings.before-dms-only.json,
права 600. Временное отключение прежнего обработчика восстановления
