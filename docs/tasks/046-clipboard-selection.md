# Задача 046: копирование и выбор истории Win+V

## Проверка контекста

Изучены WORKFLOW.md, constitution.md, architecture.md, devplan.md,
DEPLOYMENT.md, tasks/PROCESS.md и текущая реализация DMS/буфера main.

## Статус

В работе.

## Причина и цель

Пользователь сообщает: после выбора записи в Win+V текст не вставляется,
в том числе после копирования. В main осталась служба
`wl-paste --watch xclip`, массово выдающая BadWindow и повторно
публикующая содержимое буфера. В изменённом ClipboardEntry.qml одинарное
нажатие только выбирает строку; действие копирования перенесено на двойное.
Восстановить надёжное копирование и понятное действие выбора записи.

## Область изменения

Удалить устаревшую службу из hosts/main/clipboard.nix и её импорт.
В общем изменении DMS сохранить просмотр при наведении, вернуть
действие по нажатию. Режим немедленной вставки уточняется у пользователя.
Историю и содержимое буфера не очищать; личный текст не выводить.
Ядро, графические драйверы и сетевые настройки не менять.
Общее изменение DMS проверить вычислением затронутых хостов;
применить только main. Для применения допустим перезапуск cosmic-dms,
без перезапуска Hyprland и пользовательских приложений.

## Проверка

- [ ] Выбор записи вызывает копирование/вставку, наведение — просмотр.
- [ ] Служба wl-paste/xclip удалена из конфигурации main и остановлена.
- [ ] Проверены сборка main и область действия общего изменения.
- [ ] После применения DMS работает, ошибок QML нет, история сохранена.
- [ ] Пользователь подтвердил копирование и выбор записи через Win+V.

## Возврат

Сохранить предыдущую систему и закрытую копию настроек DMS.
Вернуться через `sudo nixos-rebuild switch --no-reexec --store-path ПУТЬ`.
Для диагностической остановки службы до применения достаточно
`systemctl --user start wayland-to-x11-clipboard.service`.
Содержимое буфера при необходимости сохранять только в закрытом каталоге,
без публикации в журнале и репозитории.
