# Фиксированные пути сетевых команд MantaRay

Дата: 2026-10-27. Состояние: выполняется.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT и задача 042. Пользователь получил при подключении ошибку
«Linux autoRoute requires iproute2 (`ip` was not found)».

## Причина и решение

iproute2 включён в PATH установленной службы. Двоичный файл MantaRay
содержит фиксированные пути /usr/sbin/ip, /usr/bin/ip и /bin/ip;
первые два в NixOS отсутствуют. Поиск через PATH для этой проверки
недостаточен. Аналогично присутствуют фиксированные пути nft и resolvectl.

В общем модуле службы создать набор сетевых команд из закреплённых
пакетов iproute2, nftables и systemd. Через TemporaryFileSystem=/usr:ro
и BindReadOnlyPaths предоставить этот набор как /usr/bin и /usr/sbin
только в пространстве монтирования службы. На самой системе новые
каталоги и ссылки не создавать, двоичный файл производителя не менять.

Пробная отдельная служба с такими настройками успешно выполнила
/usr/sbin/ip -Version; после её завершения /usr/sbin на основной системе
по-прежнему отсутствует. Это проверяет совместимость монтирований с
ProtectSystem=strict до изменения рабочего модуля.

## Область и ограничения

Те же пять графических конфигураций, что в задаче 042; srv-home-min
не затронут. Применение только на main. Не менять подписки пользователя,
драйвер, экраны, шрифты, другие VPN и зависимости flake. Не подключать
реальный туннель автоматически. Перезапустить только службу MantaRay,
поскольку ей нужно новое пространство монтирования.

## Проверка

- [ ] Проверить пути модуля во всех шести конфигурациях.
- [ ] Собрать main из записанного коммита, проверить ядро и план служб.
- [ ] Применить; служба работает без повторных аварийных запусков.
- [ ] В пространстве службы реально доступны ip, nft и resolvectl
      по фиксированным путям; на основной системе пути не добавлены.
- [ ] Маршруты, DNS, экраны и остальные службы сохранены; исправление
      записано в main и develop.

Проверка команд через nsenter в пространство монтирования службы:
/usr/sbin/ip -Version, /usr/sbin/nft --version, /usr/bin/resolvectl --version.
Это устраняет конкретную причину ошибки; успешность настоящего соединения
пользователь проверяет повторной попыткой со своей подпиской.

## Возврат

Предыдущее поколение и материалы сохраняются в каталоге, указанном
в ~/.local/state/mantaray-paths-latest. Возврат: предыдущее поколение
или отмена настроек монтирования с пересборкой. Прежнее поколение снова
не сможет найти ip при создании туннеля. Личные данные не изменяются.
Долгую сборку оставить отдельной службе; проверка через 3–5 минут.
