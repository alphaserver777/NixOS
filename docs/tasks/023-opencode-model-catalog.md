# OpenCode: актуальный каталог и бесплатные служебные запросы

Состояние: done. Дата: 13 октября 2026 года.

Прочитаны WORKFLOW, constitution, architecture, devplan, PROCESS,
DEPLOYMENT, TEMPLATE; связанные задачи 005, 013 и 022.

## Причина и цель

Пользователь получил ошибки протокола Big Pickle и недоступности MiniMax
M2.5 Free. Журнал дополнительно показывает отказ GPT-5 Nano для заголовка:
Rate-limited models require a workspace.

Официальная сборка 1.18.30 включает снимок models.dev от 4 апреля:
Big Pickle использует @ai-sdk/anthropic и /zen/v1. Живой каталог задаёт
@ai-sdk/openai-compatible и /inference/v1; MiniMax M2.5 Free deprecated.
Загрузчик сначала возвращает локальный/встроенный снимок, а обновляет
каталог в фоне. Поэтому первый процесс успевает зафиксировать старые
параметры провайдера. После обновления каталога новые CLI-запросы
Space Bunny Free и Big Pickle оба ответили OK с cost=0.

Цель: перед стартом клиента загрузить актуальный каталог при устаревшем
кэше и выбрать доступную бесплатную модель для новых конфигураций,
включая служебные запросы. Явные настройки пользователя сохраняются.

## Изменение

- Лёгкая обёртка официального пакета, общий источник для всех систем
  и самостоятельных Home Manager окружений; версия и flake.lock прежние.
- Перед запуском интерфейса/run/serve/web обновлять стандартный каталог,
  если он отсутствует или старше пяти минут. Ограничить ожидание 20 сек;
  при отсутствии сети оставить кэш. --version/--help и административные
  команды не требуют сети. Пользовательские источники каталога и запрет
  обновлений сохраняются.
- Существующая однократная инициализация основной/малой модели
  Space Bunny Free действует во всех Home Manager окружениях.
  Любой явно заданный model в opencode.json сохраняется; opencode.jsonc
  имеет более высокий приоритет и не изменяется.
- При первом запуске на хостах без Home Manager ту же инициализацию
  выполняет обёртка. Это явно описанное исключение для серверов без HM:
  изменяемый пользовательский файл создаётся штатным пользователем,
  прежние настройки/подключения не заменяются.
- Открытые пользовательские сеансы не завершать: для новых параметров
  требуется новый процесс OpenCode и выбор доступной модели.

## Возврат

Поколение Huawei до изменения: 143, commit b2be29e.
sudo nixos-rebuild switch --rollback возвращает прежний launcher.
Для возврата личных настроек использовать config-before.json в
~/.local/state/nixos-opencode-free, если копия была создана.
Если opencode.json создан впервые, его удаление возвращает прежнее
отсутствие модели по умолчанию; удалить default-initialized только
если нужна повторная инициализация. Сеансы, ключи и кэш не удаляются.

packages/opencode/src/provider/provider.ts и официальная таблица
