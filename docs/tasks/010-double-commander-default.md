# Double Commander как основной файловый менеджер

Состояние: выполняется.

Прочитаны правила, архитектура, план, применение и предыдущая задача 009.
Пользователь просит оставить Double Commander единственным файловым
менеджером рабочего стола, восстановить запуск и назначить его штатным.

Double Commander 1.2.4 из текущего набора Qt5 зависает при запуске;
с отдельными чистыми настройками завершается ошибкой 216. Проверяется
новый пакет из уже закреплённого дополнительного набора nixpkgs.
Личные настройки копируются до первого запуска новой версии.

Изменения: отдельный модуль Home Manager файлового менеджера, обработчик
папок и Win + E / Win + Shift + R. Удаление Nemo и PCManFM из пакетов
рабочих машин, прежнего модуля PCManFM и терминальных менеджеров
Ranger / Midnight Commander из общего пользовательского окружения.
Средства подключения накопителей, GVfs и средства выбора файлов
в других приложениях сохраняются. Серверные конфигурации не применяются.

Проверка:

- [x] Double Commander открывается с сохранёнными личными настройками.
- [ ] Открытие папки через xdg-open и Win + E запускает Double Commander.
- [ ] Остальные файловые менеджеры отсутствуют в установленном окружении.
- [ ] Сборка и применение x-disk успешны, оформление DMS и календарь работают.

Проверка программы выполняется локально до применения по прямому указанию
пользователя. Новые общие настройки предназначены для desktop-хостов;
другие физические машины недоступны и не изменяются.
Возврат: предыдущее поколение системы, история Git, сохранённая копия
~/.config/doublecmd. Проверочные процессы завершаются после диагностики.
