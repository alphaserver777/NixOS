# Задача 052: общий справочник Navi

## Контекст и статус

В работе. Пользователь вводит df в Navi и не получает результатов.
Задача 051 подключила только 35 собственных команд; общий каталог не был
подключён. Прямое navi --tldr df также падает: не включена поддержка
клиента Tealdeer. Изучены документы процесса, архитектура, задачи 050/051,
текущие настройки и документация Navi/denisidoro/navi-tldr-pages.

## Изменение

Добавить готовый общий каталог denisidoro/navi-tldr-pages из закреплённой
ревизии с контрольной суммой, только разделы common и linux. Сохранить
собственную русскую подборку и каталог личных дополнений. Включить
client.tealdeer для navi --tldr. Добавить русские примеры df в раздел файлов.
Команды по Ctrl+G и обычному вызову по-прежнему вставляются без выполнения.
Пакеты, клавиши и остальные настройки не менять. Общие страницы каталога
на английском, собственные описания и tldr ru/en сохраняются.

## Проверка

- [ ] Зафиксированы ревизия и контрольная сумма источника, подсчитан каталог.
- [ ] Обычный поиск Navi находит df и команды других общих программ.
- [ ] navi --tldr df --print работает с установленным Tealdeer.
- [ ] Русские подборки и пользовательский каталог сохранены.
- [ ] Собрано и применено новое поколение, исходники отправлены в main/develop.

## Применение и возврат

Применять Home Manager через небольшую системную сборку из коммита,
сохранить прежнее поколение y7b1w0lb0bq4v2q2hb2988ddflpyk407 и настройки.
Перед переключением проверить неизменность ядра и системных служб.
При долгой сборке оставить отдельную службу и сообщить время следующей
проверки. Возврат — nixos-rebuild switch --rollback. Личные шпаргалки
и историю команд не удалять, flake.lock и другие зависимости не обновлять.
