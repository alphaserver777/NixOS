# Локальный помощник «Профессор IT»

Запуск:

```bash
cd /home/admsys/Nixos/nixos-config
nix run .#harness-agent
```

Интерфейс будет доступен только на этом компьютере по адресу
`http://127.0.0.1:3080`.

## Подключение бесплатной модели

1. Создайте учётную запись B.AI и получите ключ программного доступа.
2. В настройках DeepSeek Harness добавьте поставщика B.AI с адресом
   `https://api.b.ai/v1` и ключом доступа.
3. Для первого теста выберите временно бесплатную модель, указанную в кабинете
   B.AI, например GLM-5.3-Flash или Qwen3.8-Flash.

Ключ вводится только в локальном интерфейсе. Не записывайте его в этот
репозиторий, чат или файл `.env`, пока не будет настроено защищённое хранение.

## Первый тест

```text
Изучи MARKETING/FUNNEL.md и TEST-DRIVE-COURSE/README.md.
Назови три наиболее рискованных места в воронке и предложи одну проверяемую
гипотезу для каждого. Не меняй файлы.
```

Помощник работает только с черновиками. Отправка сообщений, изменение CRM,
рекламы, платежей и серверов запрещены его инструкцией.

## Постоянная работа на сервере

Контейнер, Telegram-интерфейс и ежедневный запуск описаны в
[`server/README.md`](server/README.md). Серверная версия работает с отдельной
копией маркетингового репозитория рядом с базой знаний `/root/professor_ot`.
