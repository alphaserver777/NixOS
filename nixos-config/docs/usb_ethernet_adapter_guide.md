# Инструкция по работе с USB Ethernet-адаптером в NixOS

В вашей системе NixOS управление сетевыми подключениями осуществляется через `NetworkManager`. Это делает использование внешних USB Ethernet-карт максимально простым.

## 1. Основной принцип: Plug and Play

Просто подключите USB Ethernet-адаптер к вашему компьютеру. `NetworkManager` автоматически обнаружит новое устройство, создаст для него профиль подключения и попытается получить IP-адрес по DHCP от вашего роутера.

В 99% случаев никаких дополнительных действий не требуется.

## 2. Как проверить статус подключения

Вы можете убедиться, что адаптер работает, с помощью нескольких команд в терминале.

### Просмотр сетевых интерфейсов

Выполните команду `ip addr`. В списке вы должны увидеть новый интерфейс (например, `enp0s20u9`), у которого есть `inet` адрес (например, `192.168.31.149`).

```bash
ip addr
```

### Просмотр статуса в NetworkManager

Команда `nmcli` — это основной инструмент для управления `NetworkManager` из командной строки.

-   **Показать все сетевые устройства и их статус:**
    ```bash
    nmcli device status
    ```
    Вы увидите ваш USB-адаптер в списке со статусом `connected`.

-   **Показать активные профили подключений:**
    ```bash
    nmcli connection show
    ```
    Для вашего адаптера будет создан профиль с именем вроде `Wired connection 1`.

### Проверка доступа в интернет

Самый простой способ — "пропинговать" известный адрес, например, DNS-сервер Google.

```bash
ping 8.8.8.8
```

Если вы видите ответы, значит, интернет через адаптер работает.

## 3. Управление подключением

Хотя всё происходит автоматически, вы можете управлять подключением вручную.

-   **Отключить интерфейс:**
    ```bash
    nmcli device disconnect enp0s20u9
    ```
    *(Замените `enp0s20u9` на имя вашего интерфейса)*

-   **Подключить интерфейс:**
    ```bash
    nmcli device connect enp0s20u9
    ```

## 4. Что делать, если не работает?

1.  **Проверьте кабель:** Убедитесь, что Ethernet-кабель надежно подключен к адаптеру и роутеру.
2.  **Переподключите устройство:** Отключите и снова подключите USB-адаптер.
3.  **Проверьте `dmesg`:** Выполните команду `dmesg -w` и посмотрите на последние сообщения ядра. Это может помочь диагностировать проблемы с оборудованием.
4.  **Перезапустите NetworkManager:**
    ```bash
    sudo systemctl restart NetworkManager
    ```

## 5. Конфигурация в NixOS

Как мы уже выяснили, в вашем файле `configuration.nix` (через модуль `nixos/modules/net.nix`) уже есть строка:

```nix
networking.networkmanager.enable = true;
```

Этого достаточно для автоматической работы большинства USB-устройств. Вам **не нужно** вносить изменения в конфигурацию для стандартного использования адаптера.
