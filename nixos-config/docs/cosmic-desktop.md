# Космический рабочий стол

Изменения находятся в ветке `feat/cosmic-desktop`. Основа — сохранённое обновление
NixOS 26.05 в ветке `upgrade/nixos-26.05`, изменение `aa8ba5c`.

7 октября 2026 года применено на `x-disk` как поколение 236. Поколение 235
сохранено для возврата. Проверены работа панорамы на двух экранах, открытие
поиска, обзора столов и меню панели; службы работают без перезапусков.
Настройки `main` успешно проверены вычислением Nix, геометрия трёх экранов —
проверкой расчёта и стыков изображения. На сам компьютер `main` изменения
не применялись.

Окна непрозрачные, с тонкой сине-сиреневой рамкой, округлением, мягкой тенью
и короткими переходами. Панель одинакова на всех подключённых экранах;
сведения о процессоре, памяти и накопителе доступны через её меню.
Вход, блокировка и рабочий стол используют общие космические обои.

| Клавиши | Действие |
|---|---|
| Win + R или Win + пробел | Приложения и общий поиск |
| Win + V | История копирования текста и изображений |
| Win + Tab | Обзор столов на всех экранах, перенос окон мышью |
| Win + D | Управление системой и сведения о ней |
| Win + N | Уведомления |
| Win + M | Выбор режима рабочего стола |
| Win + Ctrl + W | Работа |
| Win + Ctrl + V | Видео |
| Win + Ctrl + P | Показ |
| Win + Ctrl + Backspace | Обычный режим |
| Win + F12 | Flameshot: выделение на любом экране |

В поиске `/` включает поиск файлов, `=` — вычисления, `$` — переход к окнам,
`:` — историю копирования, `@` — поиск в интернете. Новый поиск хранит новую
историю копирования; прежняя история cliphist сохраняется.

«Работа» размещает браузер, редактор и терминал по доступным экранам,
запускает отсутствующие приложения. При двух экранах редактор и терминал
находятся на разных столах правого экрана. «Видео» разворачивает текущее окно
и предотвращает засыпание. «Показ» открывает обзор всех столов.
«Обычный» возвращает распределение столов и ранее перемещённые окна;
запущенные приложения остаются открытыми. Ручное перемещение окна на другой
стол после включения режима сохраняется.

Панорама учитывает все активные экраны, их положение, масштаб и поворот,
включая экран над основным у `main`. Зеркальные выходы не считаются отдельными
частями панорамы. После изменения состава экранов фон пересчитывается.
Временные части находятся в `~/.cache/cosmic-desktop/panorama`;
состояние режима — в `~/.local/state/cosmic-desktop`.

Исходные обои созданы встроенным средством создания изображений.
Файл: `wallpapers/cosmic-panorama.png`, размер 1672 × 941.
Исходный запрос сохранён в `wallpapers/cosmic-panorama.prompt.txt`.

Сборка выполняется отдельной службой `nixos-cosmic-desktop-build`.
Состояние и журнал: `~/.local/state/nixos-cosmic-desktop/build-status`
и `build.log`. Предыдущая система записана в `previous-system`.

Для возврата после применения: `sudo nixos-rebuild switch --rollback`.
При проблеме с загрузкой в меню NixOS можно выбрать предыдущую сохранённую
систему. Старые поколения и их загрузочные файлы не удаляются.
